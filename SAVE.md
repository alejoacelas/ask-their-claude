# Saving the report and handing it over

You're reading this because a prompt linked here. "The person" means whoever pasted that prompt into their assistant.

## Save

If you can create a Google Doc in the person's Google Drive, save the report there as a new doc, without sharing it with anyone. Otherwise save it as one Markdown file (in a chat app, a downloadable file). Change nothing else.

## Format

Format the doc for easy reading. If you create it from HTML or Markdown, the structure carries over:

- Title in the Title style, sections as Heading 1 and their parts as Heading 2. Don't bold headings or use bold run-in labels instead of headings.
- Separate paragraphs with a blank line, so each paragraph has space after it. One idea per paragraph.
- Put each excerpt in a block quote, with its source (who, where, date) on its own short line above it. Keep your connecting sentences as normal paragraphs between them.
- Turn links into short link text ("the project plan"), not bare URLs.
- Give the overview table a header row.

After saving, read the doc back and check it: the title and headings use the styles above, paragraphs have space between them, excerpts are block quotes, and no Markdown symbols (**, #, >) show as text. Fix anything that's off in that same doc rather than making a new copy.

## Hand over

In at most about 100 words: the link or file, the one to three borderline items that matter most, each with a suggested edit, who is named in one line, and a reminder to check it before sharing. Don't repeat the report.

## Optional extra: a few full conversations

After the hand-off, send one short message offering this:

- Name three to five of the person's AI conversations that the report draws on most, numbered, each with its title, date and one line on why it would help the reader.
- Say exactly what would be shared: only the conversations they pick, in full, with both their messages and the assistant's replies. You'll remove credentials, account numbers and other people's contact details, and nothing else. Each is saved as its own new document next to the report (a Google Doc if you can create one, otherwise a file), shared with no one, so they can read it before sharing.
- Ask them to reply with the numbers they want, "all", or "0" to skip. Skipping is fine: the report stands on its own.

Save only what they pick, then give them the links in one line.
