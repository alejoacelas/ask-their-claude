# Ask their Claude: shared guides

Prompts already sent link to these files, and a Google Doc mirrors them: the four guides on its Guides tab, QUESTIONS and TEMPLATE on its second tab. Change them only from the private test repository (`~/best/work/sharing/prompt-lab`), whose `bin/prompt-version release` tags this repository and rewrites both tabs. Write the files without hard line wraps: the Doc import turns each wrapped line into a line break.
